# Changelog

All notable changes to Biomes O' Plenty for Minecraft 1.12.2 are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

Versions continue from 7.0.1.2445, the last release built by hand. Every commit must raise `build_number` in `build.properties` by one and add a section for the new version here. The pull request check fails otherwise, and merging publishes the newest version using its section as the release notes.

## [7.0.1.2446] - 2026-11-09

### Changed

- New versions are now built and published automatically.

### Security

- Biomes O' Plenty requires Forge 14.23.5.2858 or later, which includes the log4j exploit fix.
